# תאוריה בקל

אפליקציית לימוד תיאוריה בעברית, בסגנון משחקי, על בסיס **המאגר הרשמי של משרד התחבורה** (1,270 שאלות לרישיון B, כולל תמונות).
בנויה ב־React כאפליקציית ווב מתקינה (PWA): נכנסים לקישור, מוסיפים למסך הבית, והיא נפתחת עם הלוגו, במסך מלא, ועובדת גם בלי אינטרנט.

**לאפליקציה:** https://2njy2fz4mj-code.github.io/theory-test/

## מה יש בה
- מסלול שיעורים לפי נושאים: חוקי התנועה, תמרורים, בטיחות, הכרת הרכב
- תרגול: שאלות שעוד לא ראיתם, הטעויות שלי, הכרת הרכב (כולל מרתון), שאלות עם תמונה, מעורבב
- הסבר "למה?" לכל 106 שאלות הכרת הרכב
- סימולציית מבחן: 30 שאלות, 40 דקות, עוברים עם עד 4 טעויות
- ספירה לאחור עד תאריך המבחן, וכמה שאלות חדשות ללמוד כל יום
- רצף ימים, XP, יעד יומי; ההתקדמות נשמרת במכשיר

## פיתוח
```bash
npm install
npm run dev      # שרת פיתוח
npm run build    # בנייה ל־dist/
```

כל push לענף הראשי בונה ומפרסם את האתר ל־GitHub Pages אוטומטית (`.github/workflows/deploy.yml`).

## מבנה
- `src/data/bank.json`: המאגר. כל שורה: `[מספר, נושא, שאלה, תשובות, אינדקס התשובה הנכונה, תמונה]`
- `src/data/expl.json`: הסברים לשאלות הכרת הרכב (נכתבו עבור האפליקציה)
- `public/img/`: תמונות השאלות (WebP)
- `public/icons/`: הלוגו
- `src/views/`: מסכי הלשוניות. `src/screens/`: שיעור ומבחן

מקור הנתונים: מאגר השאלות הפתוח של משרד התחבורה ב־data.gov.il.
