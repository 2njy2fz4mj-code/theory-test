# תאוריה בקל

אפליקציית לימוד תיאוריה בעברית, בסגנון משחקי, על בסיס **המאגר הרשמי של משרד התחבורה** (1,270 שאלות לרישיון B, כולל תמונות).
בנויה ב־React כאפליקציית ווב מתקינה (PWA): נכנסים לקישור, מוסיפים למסך הבית, והיא נפתחת עם הלוגו, במסך מלא, ועובדת גם בלי אינטרנט.

**לאפליקציה:** https://2njy2fz4mj-code.github.io/theory-test/

## מה יש בה
**לימוד בריכוז** (הכפתור הירוק במסך הבית): נבנה למי שקשה לו להתרכז. 5 שאלות בכל סבב, שאלה אחת על המסך באותיות גדולות, הקראה אוטומטית, התשובות נפתחות רק אחרי שהשאלה נקראה, הקשה על תשובה בודקת אותה מיד, ויוצאים מתי שרוצים בלי לאבד כלום. שאלה שטעיתם בה חוזרת באותו סבב, אחרי 10 דקות, ואחרי יום, 3 ימים ושבוע. יעד של 3 סבבים ביום, והפסקה קצרה אחרי כל 3 סבבים.

חמש לשוניות, לכל אחת תפקיד אחד:
- **בית**: איפה אתם עומדים, כפתור אחד להמשך, וארבעת השלבים עד למבחן. ספירה לאחור עד תאריך המבחן
- **לימוד**: שיעורים של 10 שאלות לפי הסדר (חוקי התנועה, תמרורים, בטיחות, הכרת הרכב), ותרגול חופשי
- **מכשילות**: 221 שאלות מהסוגים שהכי קל ליפול בהם, עם טיפ, תרגול ורשימה לשינון לכל סוג
- **טעויות**: כל מה שטעיתם בו באפליקציה, וגם המבחנים האמיתיים שנכשלתם בהם: מעלים צילום או PDF של דף הטעויות (אפשר כמה מבחנים), האפליקציה מזהה את השאלות, ומתרגלים את כולן. הקריאה נעשית בדפדפן, והדפים נשמרים רק במכשיר
- **מבחן**: סימולציה של 30 שאלות ב־40 דקות, עוברים עם עד 4 טעויות. מבחן שנקטע נשמר וממשיך מאותה נקודה

ועוד: הסבר "למה?" ל־317 שאלות, רצף ימים ויעד יומי, מצב בהיר/כהה, ועדכון אוטומטי של האפליקציה המותקנת.

## פיתוח
```bash
npm install
npm run dev      # שרת פיתוח
npm run build    # בנייה ל־dist/
```

כל push לענף הראשי בונה ומפרסם את האתר ל־GitHub Pages אוטומטית (`.github/workflows/deploy.yml`).

## מבנה
- `src/data/bank.json`: המאגר. כל שורה: `[מספר, נושא, שאלה, תשובות, אינדקס התשובה הנכונה, תמונה]`
- `src/data/expl.json`: הסברים לשאלות הכרת הרכב ולשאלות המכשילות (נכתבו עבור האפליקציה)
- `public/img/`: תמונות השאלות (WebP)
- `public/icons/`: הלוגו
- `src/lib/data.jsx`: טעינת המאגר, חלוקה לשיעורים, וזיהוי השאלות המכשילות לפי צורת השאלה (`TRAPS`)
- `src/lib/sheet.js`: קריאת דף הטעויות (Tesseract בדפדפן, PDF דרך pdf.js) והתאמת הטקסט לשאלות במאגר
- `src/views/`: מסכי הלשוניות. `src/screens/`: שיעור, מבחן, רשימת שינון ודף טעויות

מקור הנתונים: מאגר השאלות הפתוח של משרד התחבורה ב־data.gov.il.
